# Quick Start Guide - ICA Integration

## 🚀 Getting Started in 3 Steps

### Step 1: Start the ICA Proxy Server

Open a terminal and run:

```bash
cd ibm-employee-growth-platform/proxy
npm start
```

You should see:
```
[ica-proxy] listening on http://localhost:3001
[ica-proxy] base=https://api.nextgen-beta.ica.ibm.com/ica/v1 ns=agents model=YOUR_ICA_API_KEY_HERE key=set
```

✅ **Proxy is ready!**

### Step 2: Start the React Application

Open a **new terminal** and run:

```bash
cd ibm-employee-growth-platform
npm start
```

The app will open at `http://localhost:3000`

✅ **App is running!**

### Step 3: Test the ICA Features

Open your browser to `http://localhost:3000` and you'll see:

1. **AI Monthly Summary** (dark banner at top)
   - Personalized performance summary
   - Generated by ICA Ask Coach agent
   - Updates based on your metrics and contributions

2. **AI Career Nudge** (blue card)
   - Actionable career development tip
   - Identifies your weakest skill area
   - Suggests concrete improvement steps

3. **AI Career Coach** (chat interface)
   - Click the chat icon to open
   - Ask questions about career growth
   - Get personalized advice based on your profile

## 📊 What's Powered by ICA?

### 1. Monthly Performance Summary
- **Location**: Top of Employee Dashboard
- **What it does**: Analyzes your recent contributions, metrics, and skill scores to generate a personalized 2-3 sentence summary
- **Context used**:
  - Your role and current band
  - Monthly metrics (contributions, impact score, etc.)
  - Recent achievements
  - Skill assessment scores

### 2. Career Development Nudge
- **Location**: Blue card on Employee Dashboard
- **What it does**: Identifies your weakest skill area and suggests one concrete action to improve
- **Context used**:
  - All skill dimension scores
  - Gap to "exceeding expectations" threshold
  - Your career progression goals

### 3. AI Career Coach
- **Location**: Chat interface (accessible via icon)
- **What it does**: Conversational assistant for career guidance
- **Capabilities**:
  - Answers questions about IBM's band progression
  - Explains the iX India Design Goals framework
  - Provides personalized advice based on your profile
  - Suggests specific actions to build readiness
- **Context**: Grounded in your complete GrowthIQ profile

### 4. Recognition Extraction
- **Location**: Recognition inbox (when processing messages)
- **What it does**: Automatically extracts structured contributions from recognition messages
- **Context used**:
  - Message sender and channel
  - Message content
  - IBM's performance dimensions (Outcomes, Skills, Behaviors, Leadership)

## 🔧 Configuration Files

### Proxy Configuration (`proxy/.env`)
```env
ICA_API_KEY=YOUR_ICA_API_KEY_HERE
ICA_BASE_URL=https://api.nextgen-beta.ica.ibm.com/ica/v1
ICA_NAMESPACE=agents
ICA_MODEL_ID=YOUR_ICA_API_KEY_HERE
PORT=3001
```

### React App Configuration (`.env`)
```env
REACT_APP_ICA_ENABLED=true
REACT_APP_ICA_PROXY_URL=http://localhost:3001
```

## 🐛 Troubleshooting

### Problem: "Something is already running on port 3000"

The React app is already running. Either:
- Use the existing instance
- Stop it and restart: Press `Ctrl+C` in the terminal, then `npm start` again

### Problem: AI features show static text instead of personalized content

**Check 1**: Is the proxy running?
```bash
curl http://localhost:3001/api/health
```

**Check 2**: Is ICA enabled in `.env`?
```bash
cat .env | grep ICA_ENABLED
# Should show: REACT_APP_ICA_ENABLED=true
```

**Check 3**: Did you restart the React app after changing `.env`?
- Stop the app (`Ctrl+C`)
- Run `npm start` again

### Problem: Proxy shows "ICA_API_KEY is not set"

1. Check `proxy/.env` exists
2. Verify it contains the API key
3. Restart the proxy server

### Problem: 401 Unauthorized from ICA

- Verify the API key is correct
- Check if the key has expired in ICA dashboard
- Ensure you're using the correct agent ID
